### 구현 결정

Python 3.12와 discord.py를 사용했다. 탐지 엔진·SQLite 보존·Discord 이벤트를 분리했다. 봇에 Administrator 권한을 요구하지 않고 필요한 세부 권한을 안내했다. Discord는 봇·웹훅·관리자·서버 소유자 타임아웃을 지원하지 않으므로 삭제 결과와 타임아웃 실패 사유를 별도로 남긴다. 봇 입장 자체는 악성의 증거가 아니므로 알림을 기본으로 하고 등록된 ID만 선택적으로 추방한다.

오탐 방지를 위해 초기 설정은 모의 실행이다. 운영자가 차단 목록과 임계값을 검증한 뒤 실동작으로 전환한다. 일반 계정 제재 기간은 설정 예제와 동작 테스트 모두 24시간이다. 이미 타임아웃된 계정은 기간을 연장하지 않는다.

도메인 경계를 검사해 `scam.example.good.test` 같은 정상 호스트의 부분 문자열 오탐을 피하고, 유니코드 정규화와 IDNA를 사용했다. 동일 메시지 수정 이벤트는 도배 카운트를 중복 증가시키지 않는다. 공격자가 올린 원문은 로그 메시지에 재게시하지 않고 운영자 전용 텍스트 파일로 조회한다.

이미지 판별은 SHA-256 차단 목록과 동일 이미지 반복 탐지까지 구현했다. OCR·QR·새로운 사기 이미지 의미 판별은 향후 작업이다. 검토 시 이미지 해시와 파일명은 확인되지만 이미지 원본은 보존하지 않는다.

systemd는 비로그인 전용 계정으로 실행하고 코드 디렉터리는 읽기 전용, data 디렉터리만 쓰기 가능하게 제한했다. 소스에는 토큰·실제 서버 설정·사건 DB를 포함하지 않는다.

### 검증

`python -m unittest discover -s tests -v` 실행: 초기 10개 테스트 통과.

- 도메인 경계·허용 목록·제로폭 문자·URL 사용자정보 처리
- 반복 도배·메시지 수정·시간 만료·서버/계정 분리
- 악성 이미지 해시·메시지 빈도 임계값
- 설정 검증 및 24시간 기본값
- SQLite 재연결 보존·서버별 조회·검토 기록
- 모의 모드의 무제재 보장
- 실동작 모의 API에서 삭제 및 정확한 86,400초 타임아웃
- 봇/웹훅/관리자 타임아웃 제외
- 기존 타임아웃 유지
- 운영 명령 등록과 실행 권한 검사 존재

실제 토큰이 제공되지 않았으므로 Discord 실접속·역할 권한·API 응답·사용자 리눅스 서버 배포는 검증하지 않았다. 실제 운영 전 절차는 OPERATIONS.md에 기록했다. GitHub Actions의 결과는 원격 실행 완료 후 별도 확인해야 한다.

### 향후 개선

- OCR/QR 판독과 이미지 근거 보존 정책
- 신뢰할 수 있는 외부 악성 링크 평판 연동
- 다중 서버 구성 및 재시작을 넘는 도배 윈도 보존
- 분산 계정 공격/레이드 탐지와 운영자 알림 속도 제한
- SQLite I/O 비동기화, 공격 부하 시험 및 지표/외부 가동 감시

### 서비스 파일 검증 제한

Python 소스 컴파일 검사는 통과했다. `systemd-analyze verify deploy/discord-guardian.service`는 개발 환경의 `/run/systemd`가 읽기 전용이어서 완료되지 않았다. 사용자 리눅스 서버에서 서비스 등록 후 검증해야 한다.


## 후속 개발 — 공개 위협 목록과 이미지 URL 판독

사용자가 실제 악성 사이트·스팸 광고의 판별 기준과 실데이터 연동을 요청하여 구현했다. 기존의 수동 목록만 사용하는 한계를 보강했다.

- Discord-AntiScam JSON과 Phishing Army 기본 목록을 실제 HTTPS 다운로드하여 파싱·캐시했다.
- 관측 수치: 각각 36,742개 / 146,308개, 중복 제외 183,030개. 실행 시마다 바뀌는 수치다.
- 4시간 자동 갱신, 소스별 장애 분리, 정상 캐시 유지, 7일 만료, 응답 크기/형식 검증을 추가했다.
- 도메인마다 일치한 제공자 이름을 사건 근거에 남긴다. 기존 허용 목록을 우선 적용한다.
- Tesseract OCR(한국어/영어)와 zxing-cpp QR 추출 후 동일 위협 목록을 대조한다.
- 개발 환경에는 eng만 설치되어 있어 영어 OCR은 실제 실행으로 검증했고, 한국어 언어팩 설치와 테스트는 CI/운영 설치 절차에 추가했다. 한국어 OCR 인식 품질은 별도 실자료 평가가 필요하다.
- 미등록 링크와 복합 광고 문구는 운영자 검토 대상으로만 기록한다. 코인/니트로 단어 하나로 악성 확정이나 자동 제재를 하지 않는다.
- `/protection`으로 피드 갱신·만료·OCR 설치 언어와 모의 모드를 조회한다.
- Discord 원문/이미지는 피드 제공자에게 전송하지 않으며 사용자 제공 URL을 방문하지 않는다.

검증: 자동 테스트 24개 통과. 기존 10개 외에 피드 파싱·캐시·갱신 실패·제거·만료·허용 목록·실제 QR·실제 영어 OCR·과대 이미지 제한·광고 검토 전용 처리·이미지 추출 링크의 24시간 제재 연결을 검증했다. 실제 외부 피드의 다운로드와 캐시 생성도 별도 성공했다. Discord 실제 접속 및 사용자 리눅스 배포 검증은 여전히 별도다.

판별 원리와 출처는 DETECTION.md에 기록했다. 이번 변경은 공개 위협 정보와 설명 가능한 규칙을 연결한 것이며, 모든 사기를 학습한 AI 모델이라는 주장을 하지 않는다.
