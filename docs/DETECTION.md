# 판독 기준과 실제 위협 데이터

## 외부 데이터 출처

1. [Discord Scam Prevention / Discord-AntiScam](https://github.com/Discord-AntiScam/scam-links)
   - 공개 `main/list.json`을 HTTPS로 다운로드한다.
   - 프로젝트가 Discord에서 관찰된 피싱·사기 도메인을 관리한다.
   - 이 목록은 보고된 도메인 및 하위 도메인에 적용한다. 제공자는 전체 도메인이 악성 목적으로 등록된 경우에 apex 도메인을 추가한다고 설명한다.
2. [Phishing Army](https://phishing.army/)
   - 공개 기본 도메인 목록 `https://phishing.army/download/phishing_army_blocklist.txt`를 다운로드한다.
   - 제공자 헤더상 PhishTank, OpenPhish, CERT.PL 등 여러 피싱 정보원을 집계한다. 이 봇이 해당 모든 제공자에 직접 연결하는 것은 아니다.
   - 정상 공유 호스트의 하위 도메인까지 일괄 차단하지 않도록 보고된 호스트에만 정확히 일치시킨다.

원본 목록은 저장소에 복제하지 않는다. 실행 시 각 제공자의 공개 목록을 받아 로컬 `data/threat-intelligence.json`에 보관한다. 출처와 이용 조건은 원 제공자에 따른다. Discord 메시지나 사용자 URL·이미지를 외부 분석 서비스로 전송하지 않는다. 피드 제공자는 서버의 목록 다운로드 접속을 보게 된다.

## 갱신·장애·제거

- 봇 시작 시 다운로드하고 이후 4시간마다 갱신한다.
- 성공한 새 스냅샷으로 교체해 원본에서 제거된 도메인도 제거한다.
- JSON/텍스트 구조, 도메인 형식, 최소 100개 항목, 최대 12MiB 응답을 검사한다.
- 리디렉션을 따르지 않으며 요청 제한 시간은 소스별 25초이다.
- 한 소스가 실패해도 다른 소스는 갱신한다. 실패한 소스는 마지막 정상 목록을 유지한다.
- 7일 이상 된 목록은 자동 제재 근거에서 제외한다. 재부팅 후 캐시도 같은 유효기간을 검사한다.
- GitHub·Discord·공유 호스팅의 주요 루트 도메인은 외부 목록이 실수로 포함하더라도 전체 차단하지 않는다. 그 아래 실제 보고된 악성 호스트는 별도로 검사한다.
- `/protection`과 서비스 로그로 목록 수·갱신 시각·갱신 실패·만료 상태를 확인한다. 목록이 없고 다운로드도 실패하면 외부 정보에 따른 보호는 작동하지 않지만 수동 차단·도배 탐지는 계속된다.
- 명시한 `allowed_domains`는 외부 목록과 수동 도메인 차단보다 우선한다. 도배·이미지 해시 차단은 그대로 적용된다.

## 링크·사진 판독 경로

본문 / 임베드 / 이미지 OCR / QR 문자열 → 유니코드·제로폭 문자·우회 표기 정리 → 실제 목적지 호스트 추출 → 허용 목록 확인 → 수동 차단 목록 및 공개 위협 목록 대조 → 근거와 출처 기록 → 실동작 모드에서 삭제 + 일반 계정 24시간 타임아웃.

URL에 `@`가 있으면 사용자정보가 아닌 실제 목적지 호스트를 검사한다. 정상 URL 경로에 악성 도메인을 인용한 것만으로 해당 도메인에 접속한다고 판단하지 않는다. URL 외부의 bare ASCII 도메인, `hxxps://`, `[.]` 표기를 지원한다.

이미지는 처음 4개 첨부 중 각각 5MiB 이하만 다운로드한다. Pillow로 800만 픽셀을 넘는 이미지를 거부하고, 첫 프레임을 최대 2000×2000으로 축소한다. zxing-cpp로 QR/바코드를 읽고 Tesseract로 한국어·영어 OCR을 수행한다. OCR 제한 시간은 이미지당 4초이며 이미지 스캔은 최대 4개 메시지에서 동시에 실행된다. 설치된 OCR 언어만 사용하며 누락·실패는 상태/로그/사건 근거에 표시한다. 추출된 URL을 클릭하거나 방문하거나 해당 파일을 실행하지 않는다.

이미지 속 악성 링크를 인용한 보안 안내 스크린샷도 목록에 일치할 수 있다. 필요한 안내 채널·운영 계정은 예외 역할 및 모의 실행으로 오탐을 검토한다. 이미지 원본은 보존하지 않고 OCR/QR 결과·해시·파일명만 남긴다. 기록은 길이 제한에 따라 일부 생략될 수 있다.

## 미등록 광고·사칭 문맥

다음 신호 중 2종 이상이 있고 도메인/링크도 존재하면 **검토 알림만** 만든다.

- 보상·경품 미끼: 무료 니트로, free nitro, 에어드롭, airdrop, giveaway 등
- 지갑·비밀정보 요구: 지갑 연결, 시드/복구 문구, private key, 토큰 입력 등
- 인증 유도: 로그인/인증 요구, verify account, QR 스캔 등
- 긴급·위협: 계정 정지/삭제, 즉시 행동, act now, limited time 등
- 수익보장 광고: 원금 보장, 수익 보장, guaranteed profit 등

이는 AI 학습 모델이나 악성 확정 판정이 아니다. 정상 광고·인용·피싱 주의 안내도 비슷한 문구를 사용할 수 있어 문맥만으로 삭제·24시간 제재하지 않는다. 별도로 위협 목록/도배에 일치하면 그 확실한 규칙의 제재 경로를 적용한다. 새로운 사기 도메인, 난독화, 단축 URL, 이미지 의미 기반 광고, 악성 실행파일 내용 분석은 여전히 탐지 범위 밖이다.

## 실제 연동 검증

개발 중 공개 두 소스를 실제 다운로드·파싱·캐시했다. 관측한 수치는 Discord-AntiScam 36,742개, Phishing Army 146,308개이며 중복 제거 합계는 183,030개였다. 수치는 조회 시점마다 바뀌며 봇이 모든 항목의 악성을 독립적으로 확인했다는 뜻은 아니다.

도메인 수와 갱신 시각만 개발 기록에 남겼으며 실제 악성 사이트를 방문하거나 악성 파일을 실행하지 않았다. OCR과 QR은 예약된 예제 도메인을 사용한 자체 생성 이미지로 검증했다.
